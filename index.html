      Troubleshooting

      Extracted filenames look garbled

      This page assumes UTF-8 filename encoding, which is what modern ZIP tools use. A ZIP created long ago on an older non-UTF-8 system can show garbled names for anything outside plain ASCII.

      A file renamed to .zip won't extract properly

      Some files are given a .zip extension even though they're really a RAR, 7-Zip, or other archive format. Try the Universal Archive Extractor instead — it detects the real format from the file's contents, not its name.
